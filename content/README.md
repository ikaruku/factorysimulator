# content/

All data-driven game assets (no code):

- `characters/<name>/character.glb`: rigged character models generated by `tools/character-builder/` (or replaced by an artist's GLB).
- `props/`, `buildings/`, `maps/`, `emotes.json`: populated in Stages 2A, 2B, and 4 using the standardized Blender GLB asset pipeline (`docs/guides/asset-pipeline.md`).
