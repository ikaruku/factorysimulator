# content/

All data-driven game assets (no code):

- `characters/{male,female}/character.glb`: rigged base character presets (22-bone `CharacterRig` + `Idle`, `Walk`, `Run` animations) generated by `tools/character-builder/` (or replaced by an artist's GLB).
- `characters/parts/{top,bottom,shoes,bag}/<id>.glb`: standalone modular outfit part GLBs bound to `CharacterRig`, loaded on demand by `CharacterAvatar`.
- `props/`, `buildings/`, `maps/`, `emotes.json`: populated in Stages 2A, 2B, and 4 using the standardized Blender GLB asset pipeline (`docs/guides/asset-pipeline.md`).
