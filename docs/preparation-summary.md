# Preparation Summary

Source: `game-plan.md`.

## Project core

Open-world 3D multiplayer game (factory theme; factory mechanics postponed). Map generated from a PNG, flat toon style inspired by Abeto, runs in the browser on Windows laptops and Android tablets/phones.

## Stack

TypeScript strict + Vite + Three.js (client); Node.js + Colyseus (server); pnpm monorepo `packages/{shared,client,server}`, `content/`, `docs/`, `tools/`, `tests/`.

## Permanent rules

See [standards.md](standards.md). English is used for all code, comments and documentation.
